# CVBuilder1

AgentCore Runtime application (Strands SDK) for the Swiss job-seeking app.

The **CV Builder & Optimization** agent helps signed-in users craft and improve their CV /
resume: expert advice, tips and best practices, and — crucially — it can take action by
rewriting the wording of their Profile so a strong CV can be generated automatically from
the saved data. Everything is tailored to a target job (a pasted posting, a URL, or the
user's target role) and kept Swiss-appropriate.
